# Tic Tac Toe

A clean, minimalist Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://alrayyan2157.github.io/Tic-Tac-Toe/](https://alrayyan2157.github.io/Tic-Tac-Toe/)

---

## Features

- Two-player turn-based gameplay (X and O)
- Win detection — rows, columns, and diagonals
- Draw detection when the board is full
- Restart button to reset the game at any time

## Getting Started

### Play locally

1. Clone the repository:
   ```bash
   git clone https://github.com/alrayyan2157/Tic-Tac-Toe.git
   ```
2. Open `index.html` in your browser — no build step or dependencies needed.

### File structure

```
tic-tac-toe/
├── index.html
├── styles.css
└── script.js
```

## How to Play

1. Player **X** goes first.
2. Click any empty cell to place your mark.
3. The first player to get three in a row — horizontally, vertically, or diagonally — wins.
4. If all 9 cells are filled with no winner, the game ends in a draw.
5. Click **Restart** to play again.
